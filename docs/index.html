// 01

        
As regras que o código garante

        
Toda matrícula passa por ClassGroup::enroll(). Não existe outro caminho para colocar um aluno numa turma.

      

      

        

          enrollments.size() >= capacity
          
Limite de vagas

          
Turma cheia recusa a matrícula e mostra "Turma sem vagas".

        

        

          findEnrollment(s) != nullptr
          
Sem matrícula repetida

          
O mesmo aluno não entra duas vezes na mesma turma.

        

        

          if (finished) return false;
          
Turma encerrada

          
Depois de finish(), ninguém entra. Antes disso, todos estão "Cursando".

        

        

          g < 0 || g > 10
          
Nota válida

          
Nota fora de 0 a 10 é recusada, porque as notas são private e só mudam por addGrade().
